# Sources de marque

`logo-original.png`
Fichier fourni par le client : embleme ciseaux ailes, rendu dore avec biseau
et reflets, fond deja detoure (1536 x 1024, RGBA).

## Declinaisons generees

Toutes produites a partir du canal alpha de ce fichier, donc parfaitement
alignees les unes sur les autres.

| Fichier | Usage |
| --- | --- |
| `public/media/logo-carbon.png` | lockup sur fond clair (en-tete apres scroll, pages internes) |
| `public/media/logo-paper.png` | lockup sur fond sombre (hero video, pied de page, e-mails) |
| `public/media/logo-brass.png` | variante bronze, disponible si besoin |
| `public/media/logo-gold.png` | rendu dore d'origine, detoure et recadre |
| `public/icon-192.png` `public/icon-512.png` | icones PWA |
| `public/favicon.ico` | favicon multi-tailles |
| `public/og-image.png` | image de partage social |

Pourquoi une silhouette monochrome dans l'en-tete : a 28 px de haut, le
biseau et les reflets du rendu dore se transforment en bouillie et jurent
avec la palette desaturee du site. La silhouette reste nette a toutes les
tailles. Le rendu dore reste disponible pour l'impression et la signaletique.

Pour regenerer apres un nouveau fichier source : voir la section
"Direction visuelle et medias" du README racine.
